# 마지막 메시지 수정·리롤

PC ENE와 APK 양쪽에 `chat_actions_v1` 구현이 필요하다. 이전 APK와 PC는 기본 채팅 기능을 계속 사용할 수 있지만 새 버튼은 양쪽 협상이 끝나야 활성화된다. 연결한 PC가 지원하지 않으면 업데이트 안내를 표시한다.

## 사용법

1. 기존 등록으로 PC에 연결하고 전체 대화 동기화가 끝날 때까지 기다린다.
2. 마지막 사용자 메시지의 **수정**을 누르면 공개 원문으로 편집창이 열린다. 수정 후 재생성하면 해당 메시지와 답변이 교체된다. 기존 PC 첨부는 유지된다.
3. 마지막 ENE 답변의 **리롤**을 누르면 같은 사용자 입력으로 답변을 다시 생성한다.
4. 새 결과 확인이 끝나기 전에는 다른 전송·수정·리롤을 접수하지 않는다. 진행 안내는 대화 목록의 마지막에 표시된다.

마지막 공개 한 쌍만 지원한다. 과거 대화·선제 대화·파일 명령은 수정 대상으로 만들지 않는다. `/note`, `/diary`, `/obs`는 PC에서 사용한다. 편집 텍스트는 UTF-8 16,384바이트 이하의 비어 있지 않은 문장이어야 한다. 이를 넘는 PC 원문은 휴대폰 편집창에 불러오지 않는다.

## 실패하거나 연결이 끊긴 경우

- 실패하면 PC가 원래 메시지 쌍을 복원한다. 수정 초안은 남고 **보관된 편집 초안 보기**로 다시 확인할 수 있다. 동일 대상이 여전히 허용되는 경우에만 사용자가 재제출할 수 있다.
- 연결 복구 시에는 원래 요청 ID의 상태만 조회한다. 결과를 모른다는 이유로 수정·리롤을 자동 실행하지 않는다.
- 결과 확인은 완료 이후의 새 전체 대화를 받은 뒤에 끝난다. 이전 스냅샷이나 이전 연결의 상태 알림으로 버튼을 활성화하지 않는다.
- PC 실행·대화·대상이 바뀌면 보관 초안을 다른 메시지에 자동 적용하지 않는다. 현재 대화를 먼저 확인한다.
- 편집 초안과 새 메시지 입력창은 서로 독립이다. 둘 다 메모리 전용이므로 앱 프로세스 종료 후에는 사라진다. 화면 회전만으로는 요청을 다시 보내지 않는다.

구형 PC 안내를 제외한 알 수 없는 오류는 고정 안내만 표시하며 서버 예외 원문·토큰·개인 경로를 화면이나 로그에 내보내지 않는다.

## 개발 및 검증

빌드 준비와 기존 데이터 보존 절차는 [빌드·설치 안내](build-and-install.md)를 따른다. 별도 의존성 추가나 Core 다운로드는 필요하지 않다. 보유한 검증된 Core를 그대로 사용하며 APK는 로컬에서만 생성한다.

핵심 JVM 회귀는 `ChatActionStateTest`, `ChatActionRepositoryTest`, `ChatActionPresentationTest`, `ChatActionsTlsTest`다. 편집 초안·단일 요청·지연 캡처·재접속·상태 조회 시간 초과·구형 PC·실제 TLS 전송을 합성 데이터로 검사한다. `AudioRepositoryTest`·`CharacterSessionTest`는 채팅 상태 알림과 대화 갱신으로 음성 재생이나 모델 소유권이 불필요하게 바뀌지 않는지 검사한다.

`ChatActionsScreenTest`는 최신 쌍 버튼·재구성 중 중복 전송 금지·비활성·큰 글자 편집창·마지막 진행 안내를 위한 계측 소스다. APK 빌드 및 계측 코드 컴파일은 실제 단말 시험 성공을 뜻하지 않는다. 설치·실제 LAN·회전·키보드·접근성 인수와 Live2D 출시 허가 확인은 별도로 진행한다.

### 로컬 검증 기록

- PC Python 3.11·3.12 각각 전체 4,385개 통과. 기존 Windows 심볼릭 링크 생성 권한 제한 시험 1개는 제외되었다.
- Android 전체 JVM 346개 통과, 실패·오류·제외 0. offline strict lint 오류 0, 기존 경고 4개 유지.
- 개발 APK·계측 APK 빌드 완료. 기존 APK와 서명 인증서가 같으며 APK 내부 Core SHA-256도 기존 로컬 사본과 일치한다.
- 개발 APK: `app/build/outputs/apk/debug/app-debug.apk`, 38,044,374바이트, SHA-256 `9819c2d505dc530644d007ef0bbb583514c1502a031e02abff540aa7b4514486`.
- 계측 APK: `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`, 1,174,937바이트, SHA-256 `a1a2b6ed5a74bdb701df630b1d7ae720d8c0b21d83cf8b35fa9b31c60ce88e11`.

이 기록은 로컬 자동 검증·빌드 결과다. APK를 공개 업로드하거나 단말에 설치하지 않았으며 원격 CI 실행 결과를 뜻하지 않는다.
