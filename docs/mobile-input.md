# 사진·음성 입력·휴대폰 배경 사용법

PC ENE와 앱을 함께 업데이트해야 사진·STT를 사용할 수 있다. `docs/build-and-install.md`의 로컬 빌드 절차를 따른다. 기존 QR 등록은 유지하며 Core·모델을 다시 다운로드하지 않는다. APK·Core·모델은 공개 업로드하지 않는다.

## 사진

- 입력창의 `＋ → 사진 선택`에서 JPEG·PNG·정지 WebP 사진을 최대 4장 첨부한다. HEIC·움직이는 이미지·동영상은 지원하지 않는다.
- 선택만으로 업로드하지 않는다. 미리보기의 제거 버튼으로 취소하거나, 전송 버튼으로 사진과 텍스트를 함께 보낸다. 사진만 보내도 된다.
- 원본 32 MiB·한 변 32,768·1억 픽셀까지 읽고 긴 변 2,048·장당 4 MiB로 정규화한다. 메타데이터와 원래 파일명은 제거한다. 일부 준비나 업로드가 실패하면 메시지 전체를 보내지 않는다.
- 사진은 PC의 이미지 지원 AI 제공자에게 전달될 수 있다. 이미지 미지원 모델은 다른 모델/OCR로 자동 대체하지 않는다.
- 접수가 불명확하면 같은 요청 ID를 먼저 조회한다. 미접수 확인 뒤 `미접수 사진 다시 전송`으로 재시도한다. 자동으로 새 요청을 만들지 않는다.
- 초안은 회전·선택기 왕복·재연결에서 유지하고, 앱 프로세스 종료 뒤에는 복원하지 않는다. 임시 파일은 앱의 백업 제외 영역에서만 관리한다. 사용자 원본은 건드리지 않는다.
- 모바일에서 보낸 현재 등록의 사진만 썸네일로 표시한다. 기존 PC 전용 첨부는 공개하지 않는다. 편집은 텍스트만 바꾸고 기존 첨부는 유지한다.

## 음성 입력

`＋ → 음성 입력 · PC에서 인식`을 누르면 마이크 권한을 요청한다. `완료`는 녹음을 PC에 보내 인식하는 동작이며 대화 전송이 아니다. 결과를 확인한 후 전송 버튼을 눌러야 한다.

PC의 STT 설정을 사용하고 PC PTT 설정은 켜지 않아도 된다. 최대 30초 또는 PC에 지정한 더 짧은 길이로 녹음한다. 최대 길이에 도달하면 마이크만 멈추고 완료/취소를 기다린다. 60초간 완료하지 않으면 녹음을 버린다. PC 모델 준비+인식 대기는 120초이며 인식 중인 엔진은 동시에 중복 실행하지 않는다.

홈·잠금·화면 재생성·연결 종료·대화 변경·다른 채팅/TTS 시작은 녹음과 대기 결과를 취소한다. 복귀 시 자동으로 마이크를 다시 켜지 않는다. 녹음 중 초안이 바뀌면 결과 확인창에서 직접 추가한다. 합친 입력은 UTF-8 16 KiB 이하이며 녹음·미전송 전사는 파일/로그로 저장하지 않는다.

## 배경 및 효과

오른쪽 위 `⋯ → 배경 및 효과`에서 기본 배경·단색·사진을 선택한다. 어둡기 0–75%와 사진 흐림 0–16을 조절하면 자동 저장한다. 휴대폰에만 적용되며 PC로 업로드하지 않는다. 효과는 배경에만 적용되어 캐릭터와 대화창을 흐리게 하지 않는다.

새 배경과 설정 저장이 성공한 뒤에만 이전 앱 소유 사본을 정리한다. 원본 사진은 그대로 남는다. 저장 실패 시 기존 저장값을 유지하고, 손상된 배경은 기본 배경과 오류 안내로 복구한다. 배경 변경은 Live2D 재생성이나 재연결을 요구하지 않는다.

## 남은 단말 확인

실제 단말 설치·사진 선택기 왕복·첫 마이크 허용·녹음 청취·잠금/회전·큰 글자·장시간 배경 렌더링 시험은 아직 수행하지 않았다. JVM 테스트, Lint, APK 빌드와 기기 시험 소스 컴파일을 단말 시험 통과로 해석하지 않는다. Live2D 출시 허가 검토도 별도다.
