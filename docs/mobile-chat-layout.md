# 휴대폰 대화 화면 배치

캐릭터는 화면 전체를 배경으로 사용하고, 대화창은 그 위에 반투명하게 표시한다. 사용자 메시지는 오른쪽 파란 말풍선, ENE 답변은 왼쪽 흰 말풍선으로 구분한다. 마지막 대화 한 쌍의 수정·리롤 규칙은 [기존 안내](chat-actions.md)와 같다.

## 조절과 저장

- 대화창 위쪽 손잡이를 위아래로 끌어 높이를 조절한다. 기본 46%, 저장 범위는 25–84%다. 상단 도구 모음과 안전 영역을 뺀 전경 공간을 기준으로 한다.
- 우측 상단 **배치**에서도 높이를 조절할 수 있다. 화면 읽기 도구의 높이 변경 동작을 지원한다.
- 작은 화면·큰 글씨·키보드에서는 입력 공간을 위해 표시 높이만 보정한다. 이 보정은 저장된 비율을 바꾸지 않는다.
- 공간이 아주 낮으면 손잡이·상태 줄을 잠시 접고 입력칸을 한 줄로 표시한다. 상태·배치는 상단 메뉴로 연다. 키보드 때문에 상단 도구 모음까지 접힌 경우 뒤로 가기로 키보드를 닫으면 복원된다.
- 같은 배치 창에서 캐릭터 크기 50–600%, 가로·세로 위치 −300–400%를 조절한다. 기존 저장값은 초기화하지 않는다. 작은 패널에서 전체 화면으로 바뀌므로 처음에는 원하는 구도가 달라 보일 수 있다.
- 높이 변경은 캐릭터 캔버스 크기·모델을 바꾸지 않는다. 키보드 여백은 전경에만 적용한다. 실제 기기의 키보드·회전 동작은 아래 미검증 항목을 참고한다.

손을 떼거나 창을 닫으면 저장을 요청하고, 조절이 멈춘 뒤에도 자동 저장한다. 배치 창의 저장 상태를 확인한다. 대화 높이는 `noBackupFilesDir/chat_presentation/layout.json`, 캐릭터 배치는 기존 `character_presentation/placement.json`에 별도로 원자 저장한다. 최초 읽기에 실패한 파일은 자동 덮어쓰지 않는다. 저장 실패 시 마지막 정상 파일을 유지하며 재시도 버튼을 제공한다.

앱 재시작·재접속·PC 변경에도 이 휴대폰의 설정을 사용한다. PC의 창 배치·움직임 설정은 바꾸지 않는다. 대화·입력 초안·주소·토큰은 표시 설정에 저장하지 않는다. 앱 삭제나 데이터 초기화 시 보존은 보장하지 않는다.

## 연결 및 앱 설정

우측 상단 **⋯**에서 QR 연결, PC 주소 수정, 연결·재생 상태, 연결 진단, 휴대폰 배치, 캐릭터 공통 설정, 등록 해제를 연다. 등록하지 않은 상태에서는 주소 수정·등록 해제가 비활성화된다. 캐릭터 공통 설정은 연결된 PC가 지원하고 준비되었을 때만 사용할 수 있다. 등록 해제 전 확인 창은 유지한다.

대화창 손잡이 아래의 **상태 문구**를 누르면 전체 연결·음성 사유와 캐릭터 상태를 확인할 수 있다. 승인 대기 취소, 다시 연결, 캐릭터 다시 불러오기도 이 창에 있다. 상태 문구가 짧게 표시되더라도 상세 창에는 사유가 생략되지 않는다.

## 검증 범위

개발 APK는 `app/build/outputs/apk/debug/app-debug.apk`이며 SHA-256은 `d08fa90a8b6d7579a87693858df74fef9309547e3ce52b981de9bb43ae4ebf89`다. 로컬 산출물 식별값이며 공개 다운로드 파일이 아니다.

로컬 JVM 시험은 높이 범위·오염된 설정 거절·임시 화면 보정·저장 순서·실패 복구를 검사한다. 새 계측 시험은 드래그·접근성 높이 변경, 캐릭터 뷰 생성/해제와 크기, 패널의 배경 터치 차단, 메뉴·큰 글씨·초안 유지, 원자 파일 동작을 대상으로 한다.

이번 작업에서는 실제 휴대폰 설치와 에뮬레이터 실행을 하지 않았다. 계측 소스와 APK 빌드 성공은 계측 실행 성공을 뜻하지 않는다. 다음 항목은 별도 단말 시험으로 남긴다.

1. 세로·가로·분할 화면, 큰 글씨, 키보드 열기/닫기에서 입력·전송·상태·설정 접근.
2. 손잡이 드래그, 목록 스크롤, 말풍선 수정·리롤 터치가 쓰다듬기로 전달되지 않는지 확인.
3. 높이 조절·메시지·메뉴 열기에서 모델 재로딩이 없는지, 재실행 후 저장 구도가 복원되는지 확인.
4. 전체 높이에서 확대 선명도·WebGL 성능·발열·음성 출력 확인.

APK는 로컬 [빌드 절차](build-and-install.md)로 만든다. 공개 저장소에는 APK·Core·모델을 올리지 않으며 Live2D 출시 허가 확인은 별도다.
