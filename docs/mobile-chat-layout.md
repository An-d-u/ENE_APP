# 휴대폰 대화 화면 배치

캐릭터는 화면 전체를 배경으로 사용하고, 대화창은 그 위에 반투명하게 표시한다. 사용자 메시지는 오른쪽 파란 말풍선, ENE 답변은 왼쪽 흰 말풍선으로 구분한다. 마지막 대화 한 쌍의 수정·리롤 규칙은 [기존 안내](chat-actions.md)와 같다.

## PC 설정을 따르는 말풍선과 아이콘

PC의 **설정 → 동작 → 메시지 분할 표시**를 따른다. 켜면 줄바꿈·긴 문장 경계에 따라 말풍선을 나누고, 끄면 원본 메시지를 한 말풍선에 표시한다. PC의 미리보기·취소·저장도 연결 중에 반영한다. 휴대폰에 별도 분할 설정을 저장하지 않는다.

시간과 수정·생각·리롤 아이콘은 각 원본 메시지의 마지막 말풍선 바깥에 한 번만 배치한다. 작은 화면·큰 글씨에서는 아래로 이동한다. 아이콘 모양은 PC와 같고, 누를 수 있는 영역은 48dp 이상이다. 화면 읽기 도구에는 `수정`, `생각 보기`/`생각 접기`, `리롤`로 안내한다. [아이콘 출처 및 라이선스](chat-icon-notices.md)를 동봉한다.

분할은 원문·메시지 ID·수정/리롤 대상·전송 내용을 바꾸지 않는다. 마지막 대화 한 쌍만 수정·리롤할 수 있고, 생각은 해당 내용이 있는 이전 답변에서도 볼 수 있다. 진행 중에는 기존 잠금과 사유 안내를 유지한다.

문단 사이를 읽다가 분할을 전환하면 원문 글자 위치를 새 배치에 맞추며, 하단을 보고 있으면 하단을 유지한다. 같은 내용의 펼친 생각과 편집 초안은 분할 변경만으로 접거나 지우지 않는다. 긴 본문은 잘라내지 않고 보이는 말풍선 조각만 구성한다. 캐릭터·음성 세션과 휴대폰 배치 저장은 이 설정과 독립적이다.

PC와 APK 양쪽에 `chat_display_v1` 지원 코드가 필요하다. 구버전 PC에는 업데이트 안내를 표시하고 분할 없이 기존 채팅을 유지한다. 설정 확인이 지연되면 마지막 정상 값을 임시 유지하고 전경 복귀·재연결 때 다시 확인한다. 같은 등록의 값만 메모리에 보관하며 등록 해제·교체·앱 종료 후에는 보존하지 않는다. [전송 계약](../contracts/companion/v1/chat_display.md)을 참고한다.

## 생각 보기

PC와 APK가 모두 `message_thoughts_v1`을 지원하면 생각 내용이 있는 ENE 답변의 마지막 말풍선 바깥에 **생각 보기 아이콘**이 표시된다. 누르면 답변 아래로 펼쳐지고 같은 아이콘을 다시 누르면 접는다. 마지막 답변뿐 아니라 위로 스크롤한 이전 답변에서도 사용할 수 있다.

PC에 표시한 생각만 가져오며, PC 설정에서 생각 표시를 끄면 휴대폰에서도 숨긴다. 수정·리롤·재연결 후에는 새 내용을 접힌 상태로 가져온다. 내용과 펼침 상태는 휴대폰 파일에 저장하지 않는다. 조회 실패 시 해당 답변의 **다시 시도**를 누른다. UTF-8 8KiB를 넘는 내용은 잘라 표시하지 않고 PC 확인 안내를 표시한다. 구버전 PC에서는 생각 버튼 없이 기존 채팅이 유지된다.

전송·보호 규칙은 [생각 보기 계약](../contracts/companion/v1/thoughts.md)을 따른다. 계측 테스트는 작성되어 있으나 실제 단말에서 펼침·스크롤·큰 글씨 동작 확인은 별도다.

2026-10-07 생각 보기 추가 후 로컬 검증: 전체 JVM 61개 클래스·362개 시험 통과, 실패·오류·제외 0개. offline strict lint 오류 0개·기존 경고 4개, 개발·계측 APK 빌드 성공. PC 전체 pytest는 4,393개 통과·기존 Windows 심볼릭 링크 시험 1개 제외다. 두 쪽의 Core 파일과 기존 개발 서명은 유지했다.

## 조절과 저장

- 대화창 위쪽 손잡이를 위아래로 끌어 높이를 조절한다. 기본 46%, 저장 범위는 25–84%다. 상단 도구 모음과 안전 영역을 뺀 전경 공간을 기준으로 한다.
- 우측 상단 **배치**에서도 높이를 조절할 수 있다. 화면 읽기 도구의 높이 변경 동작을 지원한다.
- 작은 화면·큰 글씨·키보드에서는 입력 공간을 위해 표시 높이만 보정한다. 이 보정은 저장된 비율을 바꾸지 않는다.
- 공간이 아주 낮으면 손잡이·상태 줄을 잠시 접고 입력칸을 한 줄로 표시한다. 상태·배치는 상단 메뉴로 연다. 키보드 때문에 상단 도구 모음까지 접힌 경우 뒤로 가기로 키보드를 닫으면 복원된다.
- 같은 배치 창에서 캐릭터 크기 50–600%, 가로·세로 위치 −300–400%를 조절한다. 기존 저장값은 초기화하지 않는다. 작은 패널에서 전체 화면으로 바뀌므로 처음에는 원하는 구도가 달라 보일 수 있다.
- 높이 변경은 캐릭터 캔버스 크기·모델을 바꾸지 않는다. 키보드 여백은 전경에만 적용한다. 실제 기기의 키보드·회전 동작은 아래 미검증 항목을 참고한다.

손을 떼거나 창을 닫으면 저장을 요청하고, 조절이 멈춘 뒤에도 자동 저장한다. 배치 창의 저장 상태를 확인한다. 대화 높이는 `noBackupFilesDir/chat_presentation/layout.json`, 캐릭터 배치는 기존 `character_presentation/placement.json`에 별도로 원자 저장한다. 최초 읽기에 실패한 파일은 자동 덮어쓰지 않는다. 저장 실패 시 마지막 정상 파일을 유지하며 재시도 버튼을 제공한다.

앱 재시작·재접속·PC 변경에도 이 휴대폰의 설정을 사용한다. PC의 창 배치·움직임 설정은 바꾸지 않는다. 대화·입력 초안·주소·토큰은 표시 설정에 저장하지 않는다. 앱 삭제나 데이터 초기화 시 보존은 보장하지 않는다.

## 연결 및 앱 설정

우측 상단 **⋯**에서 QR 연결, PC 주소 수정, 연결·재생 상태, 연결 진단, 휴대폰 배치, 캐릭터 공통 설정, 등록 해제를 연다. 등록하지 않은 상태에서는 주소 수정·등록 해제가 비활성화된다. 캐릭터 공통 설정은 연결된 PC가 지원하고 준비되었을 때만 사용할 수 있다. 등록 해제 전 확인 창은 유지한다.

대화창 손잡이 아래의 **상태 문구**를 누르면 전체 연결·음성 사유와 캐릭터 상태를 확인할 수 있다. 승인 대기 취소, 다시 연결, 캐릭터 다시 불러오기도 이 창에 있다. 상태 문구가 짧게 표시되더라도 상세 창에는 사유가 생략되지 않는다.

### 문단 분할·아이콘 보완판 (2026-10-09)

검증한 소스는 ENE `924c215`, ENE_APP `cb4268d`다. `codex/companion-chat-display` 작업 브랜치에 구현했으며 이번 검증에는 main 병합·push·설치·릴리스가 포함되지 않는다. 기존 기본 폴더와 APK는 바꾸지 않았다.

- Android 전체 JVM 65개 클래스·378개 시험 통과, 실패·오류·제외 0개. offline strict lint 오류 0개·기존 경고 4개와 개발/계측 APK 빌드 성공을 확인했다.
- PC Python 3.12 전체 4,551개 통과, 기존 Windows 심볼릭 링크 권한 제한 1개 제외. Python 3.11 집중 260개 통과. 양쪽 표시 계약 3개 파일은 해시가 같다.
- 기존 개발 APK와 서명 인증서가 같고 Core 해시도 유지했다. 아이콘 고지가 APK에 포함되며, 모델·런타임 설정·등록 파일·시험 개인키가 개발 APK에 없음을 확인했다.
- 문단 중간의 원문 위치 복원과 등록 교체/해제 시 표시 캐시 폐기를 보완했다. 복원 대기 중 새 답변이 도착해도 미완료 앵커를 유지한다.

개발 APK: `app/build/outputs/apk/debug/app-debug.apk`, 38,036,983바이트, SHA-256 `5f2d7900f0694fbd2dcfb2eb4c829a48de83cde2f1807a5e659b90a589829901`.
계측 APK: `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`, 1,255,085바이트, SHA-256 `f17976269e93e83fab84dea5b1e514cc0e6fa1dc56b722ac84e0e7ca4c779470`.

실제 기기 설치·에뮬레이터·계측 실행은 하지 않았다. 새 계측 사례는 문단 전환/하단 유지/새 답변 경합, 큰 글꼴/좁은 폭, 생각 펼침, 정확한 조작 ID, 최대 줄수의 지연 구성, 캐릭터 뷰 유지에 대해 **컴파일만 확인**했다. 실제 화면 배치·스크롤 안정성·최대 장문 응답성·음성/캐릭터 동시 사용은 별도 단말 인수에서 확인해야 한다. APK·ZIP·Core·모델은 공개 업로드하지 않는다.

### 이전 화면 배치판 (2026-10-02)

2026-10-02 로컬 검증: 전체 JVM 58개 클래스·355개 시험 통과, 실패·오류·제외 0개. offline strict lint는 오류 0개와 기존 경고 4개이며 개발·계측 APK 빌드도 성공했다. 새 화면 구현 클래스가 개발 APK에 포함되었고, 기존 개발 서명과 로컬 Core 해시가 유지됨을 확인했다.

개발 APK는 `app/build/outputs/apk/debug/app-debug.apk`이며 SHA-256은 `d08fa90a8b6d7579a87693858df74fef9309547e3ce52b981de9bb43ae4ebf89`다. 로컬 산출물 식별값이며 공개 다운로드 파일이 아니다.

로컬 JVM 시험은 높이 범위·오염된 설정 거절·임시 화면 보정·저장 순서·실패 복구를 검사한다. 새 계측 시험은 드래그·접근성 높이 변경, 캐릭터 뷰 생성/해제와 크기, 패널의 배경 터치 차단, 메뉴·큰 글씨·초안 유지, 원자 파일 동작을 대상으로 한다.

이번 작업에서는 실제 휴대폰 설치와 에뮬레이터 실행을 하지 않았다. 계측 소스와 APK 빌드 성공은 계측 실행 성공을 뜻하지 않는다. 다음 항목은 별도 단말 시험으로 남긴다.

1. 세로·가로·분할 화면, 큰 글씨, 키보드 열기/닫기에서 입력·전송·상태·설정 접근.
2. 손잡이 드래그, 목록 스크롤, 말풍선 수정·리롤 터치가 쓰다듬기로 전달되지 않는지 확인.
3. 높이 조절·메시지·메뉴 열기에서 모델 재로딩이 없는지, 재실행 후 저장 구도가 복원되는지 확인.
4. 전체 높이에서 확대 선명도·WebGL 성능·발열·음성 출력 확인.

APK는 로컬 [빌드 절차](build-and-install.md)로 만든다. 공개 저장소에는 APK·Core·모델을 올리지 않으며 Live2D 출시 허가 확인은 별도다.
