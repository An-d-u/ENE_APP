# 캐릭터·음성 동반 기능 사용 및 검증 범위

2026-09-17 기준 소스 구현·자동 검증 완료, **실기기 설치와 인수는 미실시**다. 개발용 APK이며 공개 출시용 서명물은 아니다.

## 준비와 기본 사용

1. PC ENE의 `codex/companion-lan-v1` 작업 브랜치에서 ENE와 동반 앱 서버를 실행한다. PC를 끄면 앱 단독으로 대화하거나 음성을 만들 수 없다.
2. PC와 폰을 같은 개인 LAN에 연결하고 QR을 스캔한 뒤 PC에서 등록을 명시적으로 승인한다. PC가 유선이어도 같은 LAN이면 사용할 수 있도록 설계했다. 실제 LAN 시험은 별도다.
3. 전체 대화 동기화가 끝난 뒤 메시지를 보낸다. 기존 채팅 안에 캐릭터와 음성 출력 상태가 표시된다. 작은 화면·큰 글자·키보드에서는 캐릭터가 접힐 수 있지만 확인된 모델의 공통 설정은 사용할 수 있다.
4. 캐릭터 공통 설정에서 움직임·쓰다듬기·표정·허용된 장식을 조정한다. 부분 펼침/확장을 지원하며, 미전송 미리보기는 닫으면 취소된다. 이미 보낸 저장을 닫기로 되돌리지는 않는다.

설치는 사용자가 단말을 선택하고 승인한 뒤 [빌드·설치 절차](build-and-install.md)를 따른다. 합성 응답 smoke 도구는 연결 확인용이며 실제 PC의 캐릭터·TTS 수용 시험을 대신하지 않는다.

## 음성은 자동으로 전환된다

폰이 전경이고 인증 연결·대화 동기화·재생 준비가 갖춰지면 폰이 재생한다. 그렇지 않거나 준비를 거절하면 PC에서 재생할 수 있다. **폰 재생 시작을 PC가 확정한 뒤에는 단절되어도 그 음성을 PC에서 다시 재생하지 않는다.** 다음 발화부터 출력 대상을 다시 정한다. 폰의 실제 출력 장치는 Android가 선택한다. 수동 PC/폰 선택 설정은 아직 없다.

지원 전송은 16비트 PCM, 8~48kHz, 1~2채널이며 비압축 WAV와 지원 스트림을 사용한다. 발화는 최대 180초·36MiB 이하이고 형식에 따라 더 작은 상한이 적용된다. 브라우저 전용 TTS나 지원하지 않는 형식은 PC 경로를 유지한다. 재접속해서 끊긴 음성을 다시 듣거나 과거 대화의 음성을 재생하는 기능은 없다.

## 캐릭터와 설정은 어떻게 연동되는가

폰이 같은 Live2D 실행부와 검증된 모델을 직접 렌더링한다. PC 화면을 동영상으로 보내는 방식이 아니므로 표시 크기·프레임·터치 좌표까지 완전히 같다고 보장하지 않는다. 모델 선택은 PC에서만 한다. 현재 표정·동작·재생 위치 기반 입 모양을 연결하고, 쓰다듬기 기록은 PC가 수락한 정상 종료에만 최대 한 번 반영한다.

설정은 허용 공통 키 20개와 편집 가능한 장식만 제공한다. 표정·입·신체 움직임 파라미터는 보호된다. 슬라이더는 로컬에서 미리 보고 손을 뗄 때 한 번 저장한다. 충돌 시 PC 최신 값을 확인한 뒤 직접 다시 조정한다. 응답이 10초간 없으면 결과 미확인으로 처리하고 현재 값을 읽으며 자동 재전송하지 않는다. 모델이나 revision이 바뀌면 이전 조정은 이어서 저장하지 않는다.

PC 내부의 기분 계산처럼 최종 텍스트로 표현되는 기능은 기본 대화 계약을 유지하는 한 앱 UI를 새로 만들지 않아도 메시지로 볼 수 있다. 새 화면·새 제어·새 음성 형식은 별도 앱 지원이 필요할 수 있다. 이번 버전은 `audio_pcm_v1`, `character_v1`, `character_controls_v1`을 협상하며 구형 연결에 새 확장 명령을 강제로 보내지 않는다.

## 오류와 복구

| 상황 | 확인할 것 |
| --- | --- |
| 채팅은 되지만 폰에서 소리가 안 남 | 앱 전경 여부, PC TTS 사용 설정, 지원 형식과 출력 상태. 시작 후 끊긴 발화는 중복 방지를 위해 자동 대체하지 않음 |
| 캐릭터를 표시하지 못함 | 채팅·음성은 별도로 유지. PC 모델과 아래 상한 확인 후 캐릭터 다시 불러오기 |
| 설정 충돌/결과 미확인 | 최신 값 갱신을 기다린 뒤 필요한 항목만 다시 조정. 저장 버튼 연타나 자동 재전송 없음 |
| 주소가 바뀜 | 주소 수정으로 접속 후보 변경. 인증서 검증을 끄거나 다른 PC의 CA를 자동 신뢰하지 않음 |
| PC 신원/등록 변경 | 새 QR과 PC 승인을 통해 재등록. 기존 앱 데이터를 임의 삭제하지 않음 |
| 기존 캐릭터 파일 삭제 오류 | 기존 로컬 등록을 보존하고 변경 중단. 앱을 다시 열어 재시도하고, PC 승인이 이미 끝났다면 PC 등록 상태도 확인 |

모델은 Cubism `.model3.json`, 256파일·128MiB 이하, 파일당 32MiB, 텍스처 각 변 8192px 이하를 지원 범위로 삼는다. manifest는 256KiB 이하, 캐시는 최대 256MiB·2버전이며 내려받는 중인 예약과 사용 중 파일도 포함한다. 모델이 기준을 넘으면 일부만 사용하지 않고 지원 불가로 처리한다.

캐시는 PC 신원·CA·등록 세대로 분리한다. 등록 해제·승인된 교체·인증된 등록 폐기 시 이전 모델과 스트림을 해제한 뒤 캐시를 삭제한다. 정리가 실패하면 기존 로컬 등록을 보존하고 오류를 표시한다. 캐시에는 모델 자산과 정적 검증 목록만 두며 현재 설정·장식 보정·표정 선택·동작 번호는 저장하지 않는다. 구형 상태 포함 캐시는 다음 초기화에서 폐기하고, 다시 연결하면 서버의 최신 상태를 먼저 받는다.

대화·초안은 메모리 전용이라 앱 프로세스 종료 시 소실될 수 있고, 음성은 영구 파일로 저장하지 않는다. TLS와 WebView 경계 검사는 실기기의 모든 개인정보 유출 가능성을 보증하지 않는다.

## 자동 검증과 산출물

PC 구현·검증 커밋 `a66b9239`, Android `03c1a56` 기준이다. 문서 전용 후속 커밋은 앱 동작을 바꾸지 않는다.

- PC: 전체 3976개 통과·1개 제외, 84.02초. 실제 Qt/TLS와 합성 AI/TTS로 저장·쓰다듬기·대화·음성을 결합했다.
- Android: 44개 클래스·254개 시험 통과, 실패·오류·제외 0. Lint 오류 0·기존 경고 27개. offline strict 전체 단위/Lint/개발·계측 APK 빌드 성공, 52초. 최종 문서 대조에서 확인한 캐시 삭제·상태 비보관 보완 시험 8개를 포함한다.
- PC·앱 반복 수명 시험은 각각 20회. 실제 Android 렌더러/스피커가 아니라 시험 대역과 JavaScript 실행 환경을 사용했다.
