# 대화 아이콘 출처

`ic_chat_edit`, `ic_chat_thought`, `ic_chat_reroll`은 PC ENE의
`assets/web/runtime_chat_state.js`에 사용된 Lucide pencil, sparkles, rotate-ccw 경로를
Android 벡터로 옮긴 것이다. 모양은 유지하고 표시 크기·색은 Compose에서 지정한다.

[공식 Lucide 라이선스](https://github.com/lucide-icons/lucide/blob/main/LICENSE)를 확인했으며
원문 ISC 고지를 `app/src/main/assets/notices/chat-icons-LICENSE.txt`에 보관한다.
이 고지는 APK에도 포함된다. 새 아이콘 패키지 의존성은 추가하지 않는다.
